# YouTube Downloader with Confetti

이 프로젝트는 Next.js로 제작된 모바일 친화적인 유튜브 다운로더입니다.
원하는 영상의 URL을 입력하면 자동으로 정보를 조회하고, 다운로드가 완료되면 축하 효과(Confetti)가 나타납니다.

## 주요 기능
- **자동 조회**: URL 입력 시 자동으로 영상 정보를 가져옵니다.
- **다양한 포맷**: 해상도별 비디오 및 오디오 전용 다운로드를 지원합니다.
- **Confetti 효과**: 다운로드 완료 시 화려한 폭죽 애니메이션이 실행됩니다.

## 실행 방법

1. 의존성 설치:
   ```bash
   npm install
   ```

2. 개발 서버 실행:
   ```bash
   npm run dev
   ```

3. 브라우저 접속:
   [http://localhost:3000](http://localhost:3000) 으로 접속하여 확인합니다.

## 주의사항
- 모바일 기기에서의 대용량 다운로드는 메모리 사용량에 주의해야 합니다.
- 유튜브의 정책이나 기술적 변경에 따라 `ytdl-core` 라이브러리의 업데이트가 필요할 수 있습니다.
